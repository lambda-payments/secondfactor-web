Frequently Asked Questions

What does phone number validation check?+

Validation checks a number’s country code, length, and prefix against its country’s numbering rules. It can also return the number in international format.

Does a valid result mean the number is active?+

No. A number can match a valid numbering range without being assigned or active. Checking whether it is reachable requires a separate check.

Can this verify that a user owns the number?+

No. Format validation does not verify ownership. Sending a one-time code and checking the user’s response can confirm that they have access to the number.

Why might a phone number be invalid?+

The number may have an incorrect country code, too many or too few digits, or a prefix that does not match the country’s numbering plan. Check for typing errors and include the country code.

How should I enter the number?+

Start with + and the country code, followed by the number. For example, +1 415 555 0123. This form accepts spaces, parentheses, dots, and hyphens.

What is international phone number format?+

International format starts with +, followed by the country calling code and the national number. It lets a number be represented consistently across countries.

Does validation identify mobile, landline, or VoIP numbers?+

That is a separate check. Use the phone type checker for the line type, or the carrier checker for the phone company.
