About Lambda Payments

Lambda Payments builds digital wallet and banking software for banks, telecom operators, and remittance companies. These companies offer the apps under their own brands and also use a merchant platform for QR payments and settlement.

Customers use a one-time password (OTP) to sign in on a new phone, transfer money, top up a wallet, or approve a merchant payment above a set limit.

About 9% of codes failed to arrive in time

Before Lambda integrated SecondFactor.ai, every code a client app sent had to go through a single SMS route. When that route slowed down during peak hours, the app had no other way to deliver the code.

About 9 in 100 codes failed to arrive in time for customers to sign in or complete a payment.

Customers reported missing codes to their bank. Lambda usually learned about the problem the next day, when the bank opened a support ticket.

Lambda needed a backup that would work across its client apps. Several apps were already in production, and each bank used its own sender name and message templates. Building and maintaining a separate retry process for each client wasn’t practical.

Two API calls gave Lambda a backup delivery channel

Lambda integrated SecondFactor.ai into its platform so its client apps could use the same two API calls.

The first asks SecondFactor.ai to generate and send a code. The second verifies the code the customer enters.

The apps don’t need to store OTPs. Lambda’s first client app went live 11 days after its first test call.

For each request, SecondFactor.ai checks which channels the client has enabled, which ones can reach the customer’s phone, and what each costs in that country. Most of Lambda’s codes go through Viber or SMS in Nepal and through WhatsApp in India.

If the first channel doesn’t confirm delivery within 12 seconds, SecondFactor.ai automatically tries the next eligible channel. For example, if Viber doesn’t confirm delivery, SecondFactor.ai can send the code by SMS. Lambda pays for one send even when the request uses both channels.

  1. 0 sCode sent by Viber
  2. 12 sNo delivery confirmation fallback
  3. 12 sSame request sends the code by SMS
  4. BillingLambda pays for 1 send

Webhooks notify Lambda when a code reaches the customer, the customer verifies it, delivery fails, or the code expires. When a bank reports a missing code, Lambda’s support team can check the delivery record for that request, including the channel and cost.

OTP delivery reached 99.2% in the first 30 days

Lambda sent about 180,000 codes through SecondFactor.ai in the first 30 days. The delivery rate rose from roughly 91% to 99.2%, with a median delivery time of 2.4 seconds.
