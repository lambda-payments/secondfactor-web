Choose a Template in the Send Request

TemplateSid is optional. Leave it out and SecondFactor uses your default template. Include it to use one of the templates listed on your dashboard’s Templates page.

Set up a default before omitting TemplateSid. If neither is available, the request is rejected. Any template ID you provide must belong to your account.

Frequently Asked Questions

Write to support@secondfactor.ai for anything not covered here.

Do I Need a Template Before Sending an OTP?+

Yes. A send needs either a TemplateSid or a default template on your account. Without one, the request is refused and not charged.

Can I Write My Own OTP Message?+

It depends on the channel. SMS and Viber templates take your own wording with your app name and an OTP placeholder, subject to review. WhatsApp authentication templates use prescribed wording with configurable options.

How Long Does Template Approval Take?+

Approval timing depends on the channel and its review process. Check the template’s status in your dashboard before using it for live delivery.

Do All Channels Use the Same Message Format?+

No. Each channel has its own content and approval requirements. Manage the templates in one dashboard, and prepare the message format required by each channel.

Can I Use Different Templates for Signup and Login?+

Yes. Pass a different TemplateSid with each send to choose the template for that verification.

What Happens if I Send Without a Template?+

SecondFactor uses your account’s default template when you omit TemplateSid. If you have no default, the request is rejected before delivery.
