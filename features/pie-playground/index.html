How to Test an OTP

Test from the dashboard once your channel and template setup is complete.

Create an Account

Sign up for free credits, then complete the required channel and template setup.

Enter Your Number

Open the PIE Playground and send an OTP to a phone number you own.

Inspect the Route

Review the channel that was tried and any fallback in the route inspector.

Verify the Code

Enter the code from your phone to confirm the verification succeeds.

From the Playground to Your App

Call /Verifications to send a code, then /VerificationCheck with the returned SID and the code your user entered.

A check can return 200 for either a correct or incorrect code. Confirm that status is approved before granting access. Keep your API key on your server.

Read the API Documentation →

# 1. Send a code
curl -X POST "https://api.secondfactor.ai/v2/Services/$SERVICE_SID/Verifications" \
  -H "X-API-Key: $SF_API_KEY" \
  --data-urlencode "To=+9779841000000"
# 2. Use the SID returned by step 1
curl -X POST "https://api.secondfactor.ai/v2/Services/$SERVICE_SID/VerificationCheck" \
  -H "X-API-Key: $SF_API_KEY" \
  -d "VerificationSid=$VERIFICATION_SID" \
  -d "Code=482915"

Frequently Asked Questions

Write to support@secondfactor.ai for anything not covered here.

Does the Playground Send Real OTPs?+

Yes. Playground requests use real delivery channels and account credits. Test with a phone number you own.

What Does PIE Stand For?+

Price Intelligence Engine, the routing engine that selects the lowest-cost eligible channel for each OTP.

Do I Need to Write Code to Use the Playground?+

No. Send and verify codes directly in your dashboard. Complete your channel and template setup first, then use the API when you are ready to integrate.

Are Test Sends Rate-Limited?+

Yes. Per-number burst and hourly limits apply. Requests over those limits are rejected and are not charged. See the send reference for rate-limit responses.

What Happens When My Free Credits Run Out?+

Top up your balance on the Billing & credits page of the dashboard to keep sending.

Which Channels Can I Test?+

Test channels enabled on your account with the required sender and template approvals. The recipient must support the channel; fallback requires at least two eligible channels.
