What Is the PIE Playground?

The PIE Playground is the testing tool in your SecondFactor dashboard. It runs a real verification through the Price Intelligence Engine, the routing engine that picks the channel for every OTP.

You enter a phone number, SecondFactor sends a code, and the route inspector shows which channel was tried and whether a fallback happened. Enter the code you received to complete the verification.

It is the same delivery your application will get from the API, before you have written any code.

How to Test an OTP

Four steps, none of which need code.

Create an Account

Sign up for SecondFactor. New accounts receive free credits for testing.

Enter Your Number

Open the PIE Playground and send an OTP to a phone number you own.

Inspect the Route

Review the channel that was tried and any fallback in the route inspector.

Verify the Code

Enter the code from your phone to confirm the verification succeeds.

From the Playground to Your App

What the playground does in the dashboard, your backend does with two API calls: one to send a code and one to check what the user typed.

A 200 from the check means the code is correct. Keep your API key on your server, since every send is billed to it.

Read the quickstart →

# 1. Send a code
curl -X POST "https://api.secondfactor.ai/v2/Services/$SERVICE_SID/Verifications" \
  -H "X-API-Key: $SF_API_KEY" \
  --data-urlencode "To=+9779841000000"
# 2. Check the code your user typed
curl -X POST "https://api.secondfactor.ai/v2/Services/$SERVICE_SID/VerificationCheck" \
  -H "X-API-Key: $SF_API_KEY" \
  -d "VerificationSid=VEb7c8d9e0f1a2b3c4d5e6f708192a3b4c" \
  -d "Code=482915"

Frequently Asked Questions

Write to support@secondfactor.ai for anything not covered here.

Is the PIE Playground a Sandbox?+

No. SecondFactor has no sandbox. Every playground send delivers a real message and uses your credits, so test with a phone number you own.

What Does PIE Stand For?+

Price Intelligence Engine, the routing engine that selects the lowest-cost eligible channel for each OTP.

Do I Need to Write Code to Use the Playground?+

No. The playground runs in your dashboard. Your application later uses the API for the same send and check.

How Many Test OTPs Can I Send to One Number?+

Sends to a single phone number are limited to 3 in 5 minutes and 10 in an hour. Sends beyond that are refused and not charged.

What Happens When My Free Credits Run Out?+

Top up your balance on the Billing & credits page of the dashboard to keep sending.

Which Channels Can I Test?+

The channels enabled on your account. Fallback needs at least two channels that can reach your number.
